Interactive Pattern Walkthrough

Inside BOCHA’s single-agent execution loop

Gemini decides which tool declaration fits the request, the Django REST backend enforces authenticated user permissions before running any database write, and structured output returns to the model.

Illustrative static walkthrough of BOCHA Workspace’s single-agent architecture (no live backend or LLM call is executed here).

Step 1 of 6: User Prompt & Workspace Context Loaded

  1. Step 01

    User Prompt & Workspace Context Loaded

    The user message arrives alongside conversation history and the user’s profile bio, skills, and preferences from Workspace Settings.

    request.user + conversation history + workspace profile
  2. Step 02

    System Instructions & Tool Declarations Injected

    Task-planning rules, EN/AR language matching, and zero-hallucination URL citation rules frame five typed workspace tools plus DuckDuckGo search.

    tools = [get_pending_tasks, create_task, capture_inbox_item, get_projects, create_note, duckduckgo_search]
  3. Step 03

    Gemini Selects Function Calling Action

    Using google-generativeai automatic function calling, Gemini decides whether to respond directly or invoke a backend workspace or web search tool.

    function_call: create_task(...) / duckduckgo_search(...)
  4. Step 04

    Django User Isolation & Resilience Guard

    Every ORM read or write executes inside the authenticated user’s queryset scope, protected by async exponential-backoff retries with jitter and candidate model fallback.

    queryset.filter(user=request.user) · 429/503 retry + model fallback
  5. Step 05

    Structured Result Returned to Gemini

    Tool output from PostgreSQL/SQLite or live DuckDuckGo search is sent back to the model turn so the next response stays anchored in verified state.

    function_response: {"status": "ok", "grounded": true}
  6. Step 06

    Grounded Reply Delivered to Workspace UI

    Gemini summarizes completed workspace changes or cited search URLs in the React 19 + TypeScript AI Assistant chat interface.

    assistant_turn -> React Workspace UI (EN / AR)
